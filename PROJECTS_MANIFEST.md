## Sub-Project Repository Configuration

Each workspace project sub-folder in `public/projects/<project-id>` contains standard standalone project files:

```
public/projects/<project-id>/
├── index.html        # Main landing page
├── style.css         # Styling theme and design tokens
├── app.js            # Client-side interactive logic
├── package.json      # Node package configuration & repository metadata
├── README.md         # Repository documentation & preview guide
├── .gitignore        # Standard Git ignore specification
└── .git/             # Initialized Git repository
```
